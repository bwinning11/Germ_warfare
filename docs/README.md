# Docs

Design documents, research notes, and reference material. Anything that's written *about* the game rather than the game itself.

## Suggested subfolders

Create as needed.

- `design/` — Game Design Document (GDD), design pillars, mechanic breakdowns, level/world design
- `research/` — competitor analysis, genre conventions, inspirations, market notes
- `reference/` — technical references, postmortems we're learning from, articles worth keeping

## Notes

- Governance documents (`CONSTITUTION.md`, `AGENTS.md`, `DECISIONS.md`, `CLAUDE.md`, `README.md`) stay in the project root. They are not "docs" in the sense this folder means.
- The Game Design Document, once we start drafting it, goes in `design/`.
