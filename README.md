# Germ Warfare

A video game project. Title is provisional.

## Folder map

- **`CONSTITUTION.md`** — foundational principles. Start here.
- **`AGENTS.md`** — who's on the project and who's accountable for what (RACI).
- **`DECISIONS.md`** — running log of non-trivial decisions.
- **`CLAUDE.md`** — operating instructions for Claude.
- **`assets/`** — art, audio, video, fonts, and other media.
- **`code/`** — game code (when we have any).
- **`docs/`** — design docs, research, and reference material.

## How to use this folder

If you're new to the project (human collaborator), read in this order:

1. `CONSTITUTION.md` — principles
2. `AGENTS.md` — who and how
3. README of the folder you're working in
4. `DECISIONS.md` — catch up on what's already settled

Claude reads `CLAUDE.md` automatically at the start of each session.
