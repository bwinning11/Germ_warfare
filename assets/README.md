# Assets

Art, audio, video, fonts, models, and any other media used in the game.

## Suggested subfolders

Create as needed; don't pre-create empty ones.

- `art/` — concept, character, environment, UI, icons
- `audio/` — music, SFX, voice
- `fonts/` — typefaces
- `models/` — 3D models (if applicable)
- `reference/` — inspiration, mood boards, reference images and clips (clearly mark anything that isn't ours to use)

## Notes

- Large binary files belong here, not in `code/`.
- If we later add version control (git), large assets may need separate handling (Git LFS, an external bucket, or staying out of git entirely). Decision pending — will be logged in `DECISIONS.md` when made.
